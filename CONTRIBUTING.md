# 🇳🇴 Norsk

## Bidragssguide

- Sorter imports i alfabetisk rekkefølge
- Følg pep8
- Autoformatér koden med black
- Om du legger til noen nye avhengigheter, bruk `uv add <pakke>` og commit både `pyproject.toml` og `uv.lock`

# 🇬🇧 English

## Contribution guidelines

- Sort imports by alphabetical order
- Make sure your code falls in line with pep8
- Format your code with black
- If you add any dependencies, use `uv add <package>` and commit both `pyproject.toml` and `uv.lock`
